project. Back each point with a PR, a file or a number from the repo.

```markdown
# What this prototype taught

Written YYYY-MM-DD, when the prototype was parked.

## Keep

- <What worked and why: a tool, a data shape, a page pattern. Evidence: PR #n, file.>

## Change on a restart

- <Language, repo layout, data storage, site build, tests, reviews. What hurt and the evidence.>

## Facts found

- <Facts about the data or the domain that took work to find. Keep them here so nobody finds them twice.>

## Open questions

- <What the prototype could not answer.>
```
