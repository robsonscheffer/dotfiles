11 — Spec / Right Rail

.spec-rail

The rail sits alongside a panel, never inside it — panel and rail are siblings in a 1fr 172px grid row.

PANEL + RAIL

Modal Height — Embedded Context

The beneficiaries modal renders at full viewport height in the standalone app. Inside the embedded host iframe, the same height causes the host scrollbar to compete with the modal's internal scroll.

Decision — cap modal height at 80vh when isEmbedded is true.

Why systems slow down

Every system accumulates accidental complexity — the kind that comes not from the problem itself, but from decisions made under time pressure. The fix is rarely a rewrite. It's usually a patient audit of what's load-bearing and what isn't.

Complexity is never free. It's always borrowed from future maintainers.

The two kinds of debt

Technical debt isn't monolithic. There's the kind you choose — // TODO: revisit after launch — and the kind that accretes without intention. Only the first kind is manageable.
