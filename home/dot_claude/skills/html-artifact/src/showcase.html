10 — Spec / Right Rail

.spec-layout / .spec-rail

Prose in the wide column, metadata in the narrow one. The rail is read-only at-a-glance context; the decision callout names the choice and why.

Modal Height — Embedded Context

The beneficiaries modal renders at full viewport height in the standalone app, which works fine when the modal owns the page. Inside the embedded host iframe, the same height causes the host scrollbar to compete with the modal's internal scroll. Two scrollbars, two interactions, one confused user.

Decision — cap modal height at 80vh when isEmbedded is true. Scroll within the modal, not the host page.

Trade-off: short viewports (under 600px) still need an internal scroll, which is why scrollable is derived from the same flag and the measured viewport. Tested against the embedded harness at 320×568 and 768×1024.
